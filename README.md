## Синхронизация CMS с PostgreSQL в n8n

Workflow забирает детали из CMS API (с учётом пагинации), сохраняет и обновляет их в PostgreSQL, собирает CSV и отправляет его в Report API.

Технологии: n8n, PostgreSQL.

## Как работает

1. Запрашиваем детали из CMS постранично и останавливаемся, когда приходит пустой список.
2. Записываем детали в таблицу `spares`: новые добавляются, существующие обновляются по `spare_code`.
3. Выбираем все детали из базы и собираем CSV: UTF-8, разделитель `;`, без заголовка.
4. Получаем токен, убираем BOM из начала файла и отправляем CSV в `POST /report/csv`.
